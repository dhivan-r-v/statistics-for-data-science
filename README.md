# Statistics for Data Science

This repository contains hands-on statistical analysis and hypothesis testing exercises using Python, with practical examples related to business, customer analytics, operations, and experimentation.

## 📚 Topics Covered

### Hypothesis Testing
- Null and Alternative Hypotheses
- Significance Level
- P-value
- Statistical Decision Making

### Statistical Tests
- One-Sample t-Test
- Independent Two-Sample t-Test
- One-Proportion Z-Test
- Two-Proportion Z-Test
- One-Way ANOVA
- Chi-Square Test of Independence
- Chi-Square Goodness-of-Fit Test

## 🛠 Technologies & Libraries

- Python
- NumPy
- SciPy
- Statsmodels
- Jupyter Notebook

## 📊 Practical Applications

The exercises use real-world-style scenarios involving:

- Employee performance
- Customer satisfaction
- Conversion rates
- Delivery times
- Training programs
- Product preferences
- Disease occurrence
- Manufacturing quality

## 🎯 Objective

To develop a strong foundation in statistics and hypothesis testing for Data Science, Machine Learning, and AI/ML applications.
